# 计算节点合并

将**已有连线的两个计算库节点**拖近：边缘距离不超过 24 个画布单位时，目标高亮并提示“松开合并计算”。松开后显示一个计算组合框，框内列出操作，原中间连线收进组合内部。

- 按住 **Alt** 拖动只移动，不合并。多选拖动不自动合并。
- 网络输入、输入输出张量、网络层不参与这种自动合并。
- 已有组合可以继续与相连的计算节点或另一个组合合并；内部保持一层操作，避免重复嵌套。
- 外部输入、输出、分支和未连接端口保留。会形成跨组合环路的合并不触发。
- **双击组合**或点击属性面板“编辑内部操作”，查看原操作、依赖连线和参数；用面包屑返回。
- 属性面板的**拆开组合**恢复独立节点。Ctrl+Z 撤销整个拖动合并，Ctrl+Shift+Z 重做。

项目文件使用 `CalculationGroup` 节点和既有 `subgraph`/`Inlet`/`Outlet` 格式保存真实操作与依赖；不以文字替代计算，也不删除中间结果。推导沿用子图推导，仍能读取项目超参数。框内顺序为拓扑顺序，含多输入或分支时以内部连线为准。
