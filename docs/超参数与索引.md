# 模型超参数、字典字段读取与索引切片

右侧属性面板有两个标签：“节点属性”和“模型超参数”。超参数属于整个项目，在根图和子图中共享，与当前选中的节点无关。参数的添加、修改和删除可撤销、重做，保存到项目后可以重新打开。

## 模型超参数

支持 `int`、`float`、`bool`、`string` 四种字面值类型。名称使用标识符，例如 `history_steps`，最多 64 字符；项目最多 128 个超参数。不支持以另一个表达式定义超参数，所以不会产生递归依赖。

整数索引的轴和值均可引用数值参数。例：`history_steps - 1`、`self.history_steps - 1`，参数为 21 时解析结果为 20。支持正负数、括号、`+ - * / // %`；结果必须是安全范围内的整数。这里的 `self.` 仅表示当前项目超参数的别名，不读取 Python 对象。调用函数、任意属性访问、执行代码均不支持。

超参数修改后，所有引用它的索引会重新推导。未定义参数、结果不是整数、除零和索引越界会给出错误，下游停止推导。实际输入快照不会随之修改，训练工程的配置也不会被写回。

存储格式为可选的项目字段；没有该字段的旧项目仍然兼容：

```json
{
  "hyperparameters": {
    "history_steps": { "type": "int", "value": 21, "source": "手动添加" }
  }
}
```

AI Recipe 支持相同字段，项目校验与界面使用相同的参数和推导规则。命令行和 Python 采集流程见[训练输入采集](训练输入采集.md)。采集工具仅补入尚未定义的顶层标量配置，已有同名值不会被覆盖。

## 字典字段读取

位置：**计算库 → 索引与切片 → 字典字段读取**（节点类型 `DictionaryGet`）。

把“网络输入”的字典输出连接到它的输入端口，在节点属性中选择输入字典中的字段，或填写路径：

- `agent.position` 对应 `data["agent"]["position"]`。
- `agent` 返回子字典，可继续接另一个字段读取节点。
- `["key.with.dot"]` 可以读取名字中带点号的键；数组格式也支持其他非标识符键。

输出保留被读取字段的 shape、dtype 和轴含义。缺失字段或者尝试从 Tensor 继续取字典字段会明确报错。

## 索引与切片

位置：**计算库 → 索引与切片 → 索引与切片**（统一节点类型 `TensorIndex`）。模块库中不再分别列出“张量整数索引”和“切片 Slice”。

属性中的“取值方式”有两种模式，画布均显示为紧凑表达式，保留输入、输出端口：

| 方式 | 示例 | 输入 → 输出 | 参数 |
| --- | --- | --- | --- |
| 取单个元素（`mode=index`） | `[..., 2]` | `[B,P,3]` → `[B,P]` | 操作轴、索引值 |
| 取一段范围（`mode=slice`） | `[..., 2:3]` | `[B,P,3]` → `[B,P,1]` | 操作轴、开始、结束、步长 |

切片的结束位置不包含在结果中，起止留空表示轴起点/末尾，步长必须为正整数。操作轴、索引值、切片起止位置支持整数或超参数表达式，编辑时显示解析结果，离开输入框或按 Enter 后应用。整数索引移除操作轴；切片保留操作轴。支持负轴、负索引；符号维度提示长度或边界需用实际尺寸验证。

切换模式只使用当前模式的参数，另一模式的设置继续保存在节点内，切回后恢复。切换可撤销/重做，节点 ID、位置、端口和连线不变。旧 `TensorIndex` 默认作为整数索引，旧 `Slice` 自动转换为 `mode=slice`；加载时保留旧节点的自定义名称、表达式、连线、布局及子图。下次保存使用统一格式。

例如已采集的 PLUTO 输入：

```text
data : dict
  → 字典字段读取（agent.position）: float32 [2,49,101,2]
  → 索引与切片（mode=index, dim=2, index=history_steps - 1）
  → agent_pos : float32 [2,49,2]
```

这表达的是 `data["agent"]["position"][:, :, self.history_steps - 1]`。切片 `20:21` 会保留长度为 1 的轴，与整数索引 `20` 不同。

当前每个节点处理一个轴，多轴操作可依次连接。复杂 Tensor/布尔高级索引、动态逐样本索引、完整 Python 索引语法及 PyTorch 代码生成尚未实现。当前仍是结构与形状推导，不执行张量数值计算。
