# 特征拼接与动态形状

这些计算节点用于表达 PyTorch 数据流、推导 shape / dtype 与局部整数。网页不执行实际 Tensor 数值运算或训练。

## 节点与参数

| 位置 | 节点 | 用法 |
| --- | --- | --- |
| 数学运算 | Cos / Sin | 对输入逐元素计算，角度单位为弧度；保留形状。浮点输入保留 dtype，整数或 bool 输入按默认浮点类型 float32 推导。 |
| 数学运算 | 整数乘法 | a、b 接局部整数，输出两者乘积；用于 `bs * A`。它与处理 Tensor 的 Mul 分开。 |
| 分支运算 | Cat / Stack | 右侧选择输入数量 1–16，输入端口依次为 a…p。Cat 沿已有 dim 拼接，Stack 在 dim 位置增加一个新轴。Stack 的所有输入形状必须相同。 |
| 维度操作 | View | Tensor 接 `in`；shape 例如 `d0, d1, -1`，由独立整数端口 d0、d1 提供尺寸，-1 自动推导。支持 d0…d7、非负整数字面量、最多一个 -1，目标为 1–8 维。 |
| 维度操作 | Flatten | 将 start_dim…end_dim 合并。本例设 start_dim=0、end_dim=-1，对应无参数 `.flatten()`；已有节点默认 start_dim=1 保持不变。 |

节点在画布保持紧凑，参数和说明在右侧查看。Cat / Stack 的输入数量改变后，已保留端口 ID 和输入顺序不变；删除已有连线的输入前必须先断线。旧 Cat 项目未保存 input_count 时按 2 处理。

View 的 shape 在失焦或 Enter 后提交，Escape 取消。移除仍有连线的维度端口会拒绝修改；重复使用同一个 d0 只产生一个端口。具体尺寸会校验元素数量和整除条件，零尺寸与 -1 的歧义会报错；符号尺寸保留表达式并提示约束。当前没有采集 stride，不能保证真实 Tensor 满足 `torch.view` 的内存布局要求。

## PLUTO AgentEncoder 示例

`pluto.tensor-trail.json` 的 `agent_encoder` 子画布把下列五路数据接入同一个 Cat（dim=-1）：

1. position 相邻帧差分：[B,A,T-1,2]。
2. velocity 相邻帧差分：[B,A,T-1,2]。
3. heading_vec 的 cos、sin 按这个顺序 Stack（dim=-1）：[B,A,T-1,2]。
4. shape[:, :, 1:]：[B,A,T-1,2]。
5. valid_mask_vec 转 float32 后 unsqueeze(-1)：[B,A,T-1,1]。

拼接得到 [B,A,T-1,9]。本地采集样本的形状是 [2,49,20,9]。

`bs, A, T, _ = agent_feature.shape` 用 Size 读取轴 0、1、2 并传给局部参数；未使用的第四轴无需单独命名。这里的 **T 是新的独立值**，样本中为 20；历史截取的 T=21 及其关联副本继续属于原值组。两组同名 T 自动使用不同颜色：当前历史 T 为橙色、特征 T 为蓝色，各自的关联副本保持同色；颜色表达独立定义，不改变名称或数据。前后两个 agent_feature 也是不同节点：一个是四维拼接结果，一个是 View 后的三维结果。

View 的 d0 接 bs×A，d1 接新 T 的关联副本，得到 [98,20,9]。原 valid_mask 经 Any(dim=-1) 后为 [2,49]，再从轴 0 Flatten，得到 bool [98]。这里使用原 valid_mask，不使用差分后的 valid_mask_vec。

仅局部参数在多处使用时默认用关联副本就近连接。张量与其他节点从原节点分支连线，除非用户明确要求，否则不创建关联副本；右侧“创建关联副本”保留此显式操作。重新赋值得到的新值使用独立节点，不能因为名称相同就关联。
