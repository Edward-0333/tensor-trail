# 读取维度 Size

位置：**计算库 → 形状查询 → 读取维度 Size**。

输入是 Tensor，填写读取轴（逗号分隔，最多 8 个）和输出名称。例如输入 `[2,49,2]`，轴为 `0,1`，名称为 `bs,A`，分别输出整数 `bs=2`、`A=49`，等价于 `bs, A = x.shape[0:2]`。

- 支持负轴。读取超出范围的轴会报错。
- 输出是整数尺寸，不是 Tensor。零维 Tensor 与 Python 整数是不同类型。
- 输入使用符号尺寸时保留符号，例如 `B`，不虚构具体批大小。
- 读取模块使用紧凑样式，内部只显示 `Size · 轴 0,1` 等操作。每个输出可以外接“局部参数”节点，画布只显示 `bs`、`A` 等名称，数值和类型在悬停提示与属性面板查看。
- “局部参数”位于 **模块库 → 输入输出**，类型为 `LocalParameter`。双击节点或在属性面板修改名称。左侧接收整数尺寸，右侧输出相同的值，可继续连到接受整数的节点。
- 局部参数的值随上游推导更新，不是手动设置的模型超参数，也不是可训练权重；目前支持整数与符号尺寸，不把名称自动注册到超参数表达式中。
- 每个尺寸有独立输出端口。端口 ID 为按顺序固定的 `dim0`、`dim1` 等，悬停显示端口名称；修改端口名称保留已有连线，局部参数节点名称可独立编辑。
- 输出名称留空时使用默认名称。增减读取轴会增减端口；删除已连接的端口需先断开对应连线。
- 可以与相连计算节点合并，整数可通过组合边界传递；普通 Tensor 算子不会将它当成张量。

内部推导值格式：`{"kind":"int","value":2}`，符号尺寸为 `{"kind":"int","value":"B"}`。这是形状查询的结果，不读取张量元素，不生成梯度。
