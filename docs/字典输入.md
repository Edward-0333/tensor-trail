# forward 字典输入

2026-11-04：实现嵌套字典输入的结构定义、可视化编辑、保存及沿连线传递。

## 使用

1. 从模块库“输入输出”拖入“网络输入”，将节点名称改为 `data`，在属性中点击“添加字典类型与尺寸”。
2. 在属性面板用“Tensor”和“子字典”添加字段。子字典可展开并继续添加字段。
3. 编辑字段名、Tensor 形状、dtype 和轴含义。形状可以填写 `B, A, T, 2`，`[]` 表示标量，`B, 0, 2` 表示含空维度的 Tensor。
4. 画布上保留一个输入节点和一个输出端口，端口传递整份字典；网络输入节点只显示名称，类型和各字段尺寸在属性中查看。字典本身没有统一 shape。
5. 保存项目后可重新打开，字段编辑支持撤销、重做与节点复制。

“网络输入”（`ForwardInput`）未填写结构时仍可作为名称与备注标记；填写结构后输出明确的嵌套字典。模块库和新建模块目录不再提供独立的“字典输入”。旧项目中的 `DictionaryInput` 仍可读取，其字段、连接与显示保持兼容。

## PLUTO 示例

画布上方“探索示例”中选择 **“PLUTO：data 网络输入”**，进入只有 `data` 节点的输入示例。该操作与其他示例相同，会载入一个项目，可撤销返回原项目。

示例包含 `PlanningModel.forward()` 及其子模块读取的五组主要字段：

```text
data: dict
├─ agent: dict
│  ├─ position: Tensor[B, A, T, 2]
│  ├─ heading: Tensor[B, A, T]
│  ├─ velocity: Tensor[B, A, T, 2]
│  ├─ shape: Tensor[B, A, T, 2]
│  ├─ category: Tensor[B, A]
│  └─ valid_mask: Tensor[B, A, T], bool
├─ map: dict
├─ static_objects: dict
├─ reference_line: dict
└─ current_state: Tensor[B, 7]
```

`B` 是 batch 维度，`A` 是批内补齐后的 agent 数，`T` 是输入的时间长度，`L` 是地图元素数，`P` 是每条地图线的点数，`S` 是静态物体数，`R` 是参考线数，`Q` 是参考线点数。`T` 不固定为 21：PLUTO 的历史编码会从输入中取前 `history_steps` 帧。

这是依据本地 PLUTO 的 feature builder、collate 与 forward 源码整理的**输入接口示例**，不是读取真实 batch 自动生成的结果，也不包含全部训练目标和其他辅助字段。需要时可以继续补充。形状和 dtype 均可编辑。

## 数据协议与计算边界

`ForwardInput` 的可选 `params.schema`（未填写时为空字符串），以及 `DictionaryInput` 的 `params.schema`，保存结构描述 **JSON 对象**，不再把整段 JSON 转义成字符串。旧字符串格式仍可打开，有效 schema 会自动规范化为对象；无效旧文本保留在编辑器中供修正。填写有效结构后推导得到带 `fields` 的字典值：

```json
{
  "kind": "dict",
  "fields": {
    "agent": {
      "kind": "dict",
      "fields": {
        "position": {
          "shape": ["B", "A", "T", 2],
          "axes": ["batch", "agent", "time", "xy"],
          "dtype": "float32"
        }
      }
    }
  }
}
```

字段当前支持子字典和 Tensor 描述；字符串、Python 对象、list 和 tuple 等字段类型后续按需要扩展。未填写 axes 时自动生成轴名。字典类型与 Tensor 类型保持区分，不能将整份字典直接接入 Linear 等张量运算。

自定义子图的 Inlet、Outlet，以及 Identity 和 Output 可原样传递字典。计算库“索引与切片”中的“字典字段读取”可以读取 `data["agent"]["position"]`，再连接切片或“张量整数索引”。详见[超参数与索引](超参数与索引.md)。

本功能不依赖 Python/PyTorch，不执行模型、不保存真实张量数值，也不自动导入 PLUTO 模型。输入结构限定为 8 层、256 个条目和 64,000 字符，项目整体仍使用原有大小限制。

静态 `params.schema` 表达输入契约；一次真实运行的具体尺寸和 `requires_grad` 存在独立快照的 `bindings[].value` 中。选择运行时只覆盖当前推导结果，不回写 schema。详见[使用与扩展](使用与扩展.md#静态图与运行快照)。

旧 `DictInput` / `ListInput` 节点继续按既有规则迁移为文字型 `ForwardInput`，不会把历史自由备注误解释成结构数据。

## 整数时间键

2026-11-10：为 SparseWorld 的 `kwargs['temporal_ego_states'][0]` 增加整数键字典支持。
每层字典可选 `keyType: "int"`；省略或填写 `"str"` 保持原有字符串键语义。
JSON 中的字段名仍写成字符串，但不能把 Python 的整数键 `0` 与字符串键 `"0"` 混用。

```json
{
  "kind": "dict",
  "keyType": "int",
  "fields": {
    "0": { "shape": [1, 1, 21], "axes": ["batch", "ego", "state_feature"], "dtype": "float32" }
  }
}
```

“字典字段读取”的路径填写 `[0]`；若从 kwargs 一次读取，填写
`["temporal_ego_states", 0]`。这不是 TensorIndex：它不会删除 Tensor 的 batch 轴。
属性面板可以选择字典键类型，并在整数键字典中添加、重命名和删除字段。
整数键必须是安全整数，不支持同层混用整数和字符串键；旧项目无需迁移。

输入 Tensor 也支持 `uint8`，用于表示图像进入预处理前的真实类型。
只绘制到中间变量的阶段图应使用“张量变量”和“局部参数”，不要伪造 Output。
这类图可正常打开和推导，完整模型的 CLI 校验仍会报告 `MISSING_OUTPUT`，直到画出真实返回值。
