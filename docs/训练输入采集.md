# 从真实训练输入加载 data

2026-11-04：提供可选 Python 适配器，将真实 `forward(data)` 的字段类型和形状加载到 Tensor Trail 项目。网页本身仍不依赖 PyTorch。

## 当前 PLUTO 用法

先保存网页中的项目。使用已配置好的 `pluto_learn` 环境运行：

```bash
/home/vci-4/anaconda3/envs/pluto_learn/bin/python \
  /home/vci-4/LK/pluto_learn/pluto/script/export_tensor_trail_input.py \
  --project /home/vci-4/LK/pluto_learn/pluto.tensor-trail.json
```

完成后在 Tensor Trail 中点击“打开”，重新选择这个项目文件。当前浏览器内存中的图不会随磁盘变化自动更新。后续修改 batch size、模型超参数或数据配置后，可以再次执行命令采集。

更新工具也会把快照 `context.model_config` 中的顶层标量配置补入项目的 `hyperparameters`，在“模型超参数”标签页查看。以下划线开头的框架字段和嵌套对象不会导入。已有同名超参数保留，避免覆盖图中手动调整的值；再次采集只补充缺失项，已有项如需同步应在面板中明确修改。每个导入值记录采集时间来源。

该脚本复用 `pluto/run_cache_train.py` 的当前配置、模型构造、训练集 DataLoader、collate、设备转移及 `training_step`，通过模型的 forward 前置 hook 在 `PlanningModel.forward(data)` 边界采集，并立即停止。它不会运行模型主体、计算 loss、反向传播、调用优化器或写训练 checkpoint。

当前适配器支持训练入口的 `precision=32`、`CHECKPOINT=None` 配置；不支持的配置会明确报错，不会悄悄换成推理配置或其他设备。采集中的 `grad_enabled=True` 表示入口处启用了自动求导，不代表执行或验证了反向传播。输入 Tensor 的 `requires_grad=False` 不影响模型参数在实际训练中的梯度计算。

## 产物

- `pluto.tensor-trail.json`：新增或更新一个根层 `data` 网络输入（`ForwardInput`），类型为字典。画布只显示名称，属性面板可展开查看 35 个 Tensor 的尺寸与 dtype。已有其他节点、连接、布局、名称、备注和变体保留。已有字段的轴注释在维数相同时保留。
- `pluto.tensor-trail.before-runtime-时间戳.json`：修改前的原始项目备份。
- `pluto/outputs/tensor_trail/data_snapshot.json`：采集元信息，含具体 shape、dtype、device、requires_grad、输入路径、模型配置、batch size、seed、场景 token 和采集范围。

这些文件不包含 Tensor 的数值、模型权重或梯度数组。只记录一个真实 batch 的结构快照，agent 数、地图元素数和参考线数等可能随 batch 变化。

若项目中有多个可选输入，使用 `--node-id` 明确要更新的根层输入节点。目标可以是已有字典输入或网络输入，更新后统一使用 `ForwardInput` 承载字典；已有输入节点的 ID 和连线不会更换。打开的网页若有未保存内容，需要先保存，再采集并重新打开。

## 首次实际采集结果

使用 GPU `cuda:0`、batch size 2、seed 0，训练模式下采集到 8 个顶层字段、35 个 Tensor。主要字段如下：

| 字段 | shape | dtype |
| --- | --- | --- |
| `agent.position` | `[2,49,101,2]` | `float32` |
| `agent.valid_mask` | `[2,49,101]` | `bool` |
| `agent.target` | `[2,49,80,3]` | `float32` |
| `map.polygon_center` | `[2,58,3]` | `float32` |
| `map.valid_mask` | `[2,58,20]` | `bool` |
| `reference_line.position` | `[2,3,120,2]` | `float32` |
| `current_state` | `[2,7]` | `float32` |
| `cost_maps` | `[2,600,600,1]` | `float16` |

`agent.position` 的 101 是 21 帧历史加 80 帧未来；模型内部会读取或切出各自需要的部分。49 包含自车和最多 48 个周围 agent。此处的具体数值来自采集结果，而非手工输入的符号示例。

## 在自己的调试断点中导出

可在已有训练项目的 `forward` 入口、能访问真实 `data` 时调用：

```python
import sys
sys.path.insert(0, "/home/vci-4/LK/pluto_learn/tensor-trail/python")
from tensor_trail_runtime import export_input_snapshot

export_input_snapshot(data, "/tmp/data_snapshot.json", context={"source": "forward debugger"})
```

然后使用独立更新命令，将该快照写入保存的项目：

```bash
/home/vci-4/anaconda3/envs/pluto_learn/bin/python \
  /home/vci-4/LK/pluto_learn/tensor-trail/python/tensor_trail_runtime.py \
  --snapshot /tmp/data_snapshot.json \
  --project /home/vci-4/LK/pluto_learn/pluto.tensor-trail.json
```

此方法捕获的是当前调试进程中的变量；自动采集脚本则在独立进程中按当前配置读取一个真实训练 batch。两者都不是自动读取另一个进程的局部变量。

本步支持字典和 Tensor 字段。其他 Python 数据结构会报出所在路径；后续根据需要扩展。完整 forward 计算图、梯度流可视化、代码生成和自动图同步仍属于后续工作。
