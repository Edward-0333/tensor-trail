# 函数模块

位置：**计算库 → 数学运算 → 函数**，节点类型 `Function`。

函数有一个输入端口 `in` 和一个输出端口 `out`。画布只显示函数标识和名称，不展示公式或内部算术步骤。选择节点后，在右侧修改模块名称、输入变量名及数学公式。公式填写等号右侧，离开输入框或按 Ctrl+Enter 应用，支持撤销、重做和保存重开。

当前支持浮点 Tensor 的逐元素算术：输入变量、数值常量、`math.pi`（也可写 `pi`）、`+ - * / %`、括号及正负号。公式必须使用输入变量；不支持赋值语句、索引、维度归约或任意函数调用。允许的运算均保持输入的 shape、轴含义与浮点 dtype。函数模块解析有限的公式语法，不执行 Python/JavaScript 代码。

## PLUTO 第 138 行

节点名称：`角度归一化`；输入变量：`angle`；公式：

```python
(angle + math.pi) % (2 * math.pi) - math.pi
```

数据流：`angle_cat → 角度归一化 → angle`。逐元素将朝向映射到 `[-π, π)`，`π` 映射为 `-π`，正负角都适用；输入和输出均为 `float32 [2,107]`。

`%` 使用 Python / PyTorch 的取模语义，余数符号跟随除数；不能直接套用 JavaScript 对负数的 `%` 结果。标量数学参考用于验证公式，画布当前仍只校验公式和推导元数据，不运行训练 Tensor，也尚未生成 PyTorch 代码。

存储示例：

```json
  "params": {
    "argument": "angle",

```


## 可展开的辅助函数：to_vector

位置：**计算库 → 组合计算 → to_vector**，类型 `ToVector`。这是 PLUTO 辅助函数的已实现模板；画布只显示 `ƒ to_vector`，双击进入函数内部，通过面包屑返回。它有两个输入 `feat`、`valid_mask` 和一个输出 `out`，没有可训练参数。原有单输入数学公式节点 `Function` 的行为不变。

- `feat`：浮点 Tensor `[B, A, T, ...]`，时间轴为轴 2；`heading` 为三维，`position`、`velocity` 可以带末尾特征维。
- `valid_mask`：bool Tensor `[B, A, T]`，对应 `feat` 的前三个轴。
- `out`：`[B, A, max(T-1, 0), ...]`，两帧均有效时返回后一帧减前一帧，否则为零。

内部图忠实保留以下步骤：

1. `valid_mask[..., :-1] & valid_mask[..., 1:]` 得到相邻帧有效标记。
2. `while mask.ndim < feat.ndim: mask = mask.unsqueeze(-1)` 由“补齐末尾维度”节点明确表达；三维 heading 不补轴，四维位置补一个末尾单例轴。它只补维，不复制元素。
3. `feat[:, :, 1:, ...] - feat[:, :, :-1, ...]` 计算差分，`zeros_like(feat[:, :, 1:, ...])` 提供零张量。
4. `where(mask, difference, zeros)` 按条件选择。使用条件选择保留无效区间置零语义，包括差分包含 NaN 的情况。

配套新增的 `&`、逐元素减法、`Where`、`ZerosLike`、补齐末尾维度均可从计算库独立拖入，卡片只显示紧凑符号或操作名，接口与计算说明在右侧。布尔掩码的 `&` 是逐元素与，不是 `any()` 归约。

当前 PLUTO 画布的 `agent_encoder`：`heading + valid_mask → to_vector → heading_vec`；另一路 `valid_mask` 经两次切片和 `&` 得到 `valid_mask_vec`。输入为 `[2,49,21]` 时，两路输出分别为 `float32 [2,49,20]` 和 `bool [2,49,20]`。`valid_mask` 就近显示的副本通过共享引用取得同一值。
