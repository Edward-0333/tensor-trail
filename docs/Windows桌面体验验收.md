2026-11-09 完成 D5-01～D5-04，M2 Windows 开发版验收完成。当前仍通过根 `start-desktop.cmd` 启动；安装目录、EXE 分发和安装包属于下一阶段 D6。本轮未提交或推送 Git。

- 用户项目 `data/pluto.tensor-trail.json`：851,124 字节，根层 66 个节点／83 条边，含子图共 1,031 个节点／1,151 条边。

- 另用有效的 Input → Linear 分支图验证连线，并从现有模块库拖入 PLUTO 的 NATSequenceEncoder；“探索示例”中的 PLUTO Forward 输入也实际打开。

精简测量数据及 18 项观察名称保存在 [验收数据](validation/windows-desktop-experience-20261109.json)，不包含用户项目内容。完整截图、测试副本与独立 profile 留在被 Git 忽略的本机 `test-results/`。

## 实际改动

1. 大图最小缩放由 15% 降到 4%，修复“适配全图”后仍有节点落在画布外的问题。缩放和适配按钮补充中文无障碍名称。网页使用同一画布实现，也获得这项修复。
2. 提取 `views/routeStore.ts`，同一轮布局中的连线几何立即可读，订阅通知合并到一个微任务。83 条边同时发布的测试确认只通知一次，避免逐边触发订阅更新；取消预览、共享线选择和撤销行为保留。
3. 原生文件会话记住已经通过格式校验的字节指纹。再次读取相同字节时复用校验结论；读取仍有大小、UTF-8 和 SHA-256 检查，写入仍完整校验。选择后内容变化会拒绝读取，另存为选中的已有文件也不会跳过首次格式校验。

未修改项目 JSON 协议、算子语义或用户的保存文件。

## 大图性能

基线由 D5 开始前的三个产品文件重新构建；测量后自动恢复当前源码并重建。前后使用同一机器、用户副本、长文件名和 20 步原生鼠标拖动。每个比例各记录一次首次打开、两次同窗口再次打开。下表单位均为毫秒。

| DPI | 首次打开：前 → 后 | 再次打开两次均值：前 → 后 | 拖动帧间隔 P95：前 → 后 | 松键到两个动画帧：前 → 后 |
| --- | --- | --- | --- | --- |
| 100% | 861.3 → 837.4 | 608.2 → 539.1 | 13.5 → 13.6 | 70.8 → 69.1 |
| 125% | 892.5 → 813.7 | 555.6 → 537.9 | 14.1 → 13.7 | 67.3 → 65.8 |
| 150% | 818.0 → 843.3 | 553.0 → 521.8 | 13.6 → 14.0 | 76.2 → 64.9 |

六个再次打开样本的中位数为 564.0 → 534.5 ms。各组拖动帧间隔中位数约 13.3 ms，拖动观察期间前后均未捕获到超过 50 ms 的 long task。样本少、受缓存和调度影响，结果只说明本机这份项目的表现；不据此承诺稳定的提速比例或肉眼手感改善。完整手势约 0.66 秒，包含测试脚本的分步等待，不能当作单次输入延迟。

“打开”从点击打开至项目 revision、节点数量正确并经过两个动画帧，包含轮询和 IPC 开销，**不等于进程启动时间**；松键指标也只到动画帧回调，不是显示器实测输入到像素延迟。大图自动适配的范围随修复发生变化，前后并非只切换单个优化的独立消融实验。

本次没有测出需要为拖动新增 worker 的长任务，暂不增加并发推导或 Python 进程。几何通知批处理和字节校验复用的行为分别有单测；若更大项目打开仍明显阻塞，再对加载／推导分段分析。

## 保留的验证边界

- 尚未实测多显示器之间移动窗口导致的 DPI 切换，也未人工切换系统缩放；原生文件选择器使用受控回答，未认证其视觉布局。
- 鼠标事件在真实渲染窗口内执行，已检查模型变化和磁盘往返；没有将自动化通过等同于用户主观手感认可。
- 当前测试局限于本机、这份用户项目和上述示例。极端大图、触控／手写笔及不同 GPU 环境未覆盖。
- 约 729 kB 的桌面 JS 仍有构建体积提示；本轮未引入大型依赖，也未把分包当成已验证的运行性能改进。
- 安装／卸载、签名、自动更新、独立 EXE 分发在 D6／R1，Python 集成在 P1；本轮没有提前交付这些能力。

测试方法参考 [Electron WebContents 输入与调试接口](https://www.electronjs.org/docs/latest/api/web-contents) 和 [CDP Input 拖放协议](https://chromedevtools.github.io/devtools-protocol/tot/Input/)。后续执行入口为台账 **D6-01**。
