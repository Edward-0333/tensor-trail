# Figtree

Figtree is bundled locally for the editor chrome. The canvas keeps its existing
type metrics, and Chinese text uses the available CJK font on the host system.
No external font request is made at runtime.

- Author: Erik Kennedy / The Figtree Project Authors
- Source: https://github.com/erikdkennedy/figtree
- Revision: `032dfa7fe219ef3a02890d6d3add84eacc9aebfe`
- File: `fonts/variable/Figtree[wght].ttf` (normal, weights 300-900)
- Bundled as losslessly compressed `Figtree-variable.woff2` using FontTools.
- License: SIL Open Font License 1.1, included in `OFL.txt`

The typeface and restrained surface hierarchy are inspired by the Astryx Neutral
theme: https://github.com/meta/astryx/tree/main/packages/themes/neutral
The workbench styles are Tensor Trail's own implementation, not an Astryx fork.
